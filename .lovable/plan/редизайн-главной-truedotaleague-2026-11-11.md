# Редизайн главной TrueDotaLeague

## Что меняется (только интерфейс)
1. **Оформление**: небесно-голубой / белый / тёмно-синий, крупные заголовки, мягкие тени, плавные появления карточек. Добавляется тёмная тема с переключателем в шапке (запоминается на устройстве). Логотип — существующий официальный TDL.
2. **Главный экран**: TRUEDOTALEAGUE → «От любителя до чемпиона» → ваш текст. Кнопки «Смотреть турниры», «Зарегистрировать команду» (ведёт в «Моя команда»), для админа — «Создать турнир».
3. **Три дивизиона**: карточки Amateur / Challenger / Freedom с вашими пунктами. Клик открывает список турниров, отфильтрованный по дивизиону.
4. **Ближайший турнир**: берётся из базы (ближайший анонсированный / с открытой регистрацией / идущий). Название, дата и время по Казахстану (UTC+5), формат, лимит MMR дивизиона, призовой фонд, зарегистрировано X из максимума, статус регистрации, кнопка «Участвовать». Пустое состояние, если турниров нет.
5. **Рейтинг (топ-10)**: из существующей системы TDL Points. Победы/поражения считаются по сыгранным матчам, «турниров» — по итогам. Подпись «Разыгрывается в TDL Freedom». Кнопка «Полный рейтинг» — на новую страницу `/rating` с той же таблицей.
6. **Зал чемпионов**: последние завершённые турниры — дата, чемпион, финалист, счёт финала (если есть матч).
7. **Статистика**: проведено турниров, команд, игроков, сыграно матчей — реальные подсчёты.
8. **Discord**: блок с кнопкой на https://discord.gg/ZJBzeKcjvU.
9. **Меню**: Главная, Турниры, Команды, Рейтинг, Чемпионы (архив), Правила, Профиль (+ «Моя команда»). Админка видна только админам; права уже проверяются и на сервере — это не меняется.

## Важные допущения (без изменения базы)
- **Дивизион** турнира определяется по названию (содержит Amateur / Challenger / Freedom). Отдельного поля в базе нет — добавлять его не буду, если не попросите.
- **Взнос за участие** в базе не хранится — строку не покажу, пока нет данных (не выдумываю). Могу позже добавить поле в форму турнира.
- **Лимит MMR** показывается по дивизиону (16 500 / 26 500 / без лимита).

## Не трогаю
Вход через Discord, базу, RPC, права, регистрацию команд, логику турниров, данные. Тестовые турниры не создаю.

## Проверка после
Сборка, переходы, главная под гостем и админом, мобильная ширина 360 px без горизонтального скролла, светлая/тёмная тема, сверка цифр статистики с базой.
