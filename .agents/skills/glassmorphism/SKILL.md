# glassmorphism for TrueDotaLeague

Match the existing TrueDotaLeague palette. Keep text contrast and focus indicators strong over changing backgrounds. Limit backdrop-filter to small surfaces, provide a solid fallback, and test mobile performance and reduced motion. Avoid decorative glass where it obscures content.
